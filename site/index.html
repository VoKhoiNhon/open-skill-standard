01 · why

A typical setup has 100+ overlapping skills. Open Skill Standard adds the missing layer: which role a skill serves, which phase it acts in, and which artifacts it consumes and produces. From that, a router builds a short, ordered, explained chain.

  1. Descriptions overlap

    Agents pick skills by matching descriptions. Three build workflows and several reviewers that sound alike make them load the wrong one or miss the right one.

  2. The listing gets cut

    Claude Code budgets the skill listing at about 1% of the context window and drops the least-used descriptions first, so matching gets worse exactly when you install more.

02 · what you get

Four core skills, a CLI and a registry that never copies upstream content

Upstream skills are described as metadata and installed with their official commands. The router reads that metadata; your agent runs the chain.

03 · how it works

From registry to an explained chain

  1. Describe and indexThe registry and the skills installed on your machine feed a local SQLite FTS5 index.
  2. Route by phase and rolePhase, size and window first, then scoring and selection per phase, then an ordered chain.
  3. Ask whyroute --explain and route --why-not <skill> show every decision.

Both diagrams are generated from the code and the registry on every change, so they cannot drift.

05 · parallel sessions

Several agents, one project, one shared graph

Each session declares the paths it works on. After an edit, open-skill session update refreshes one shared Graphify graph and warns, never blocks, when the change reaches another session's scope.

06 · measured

Scored on requests it was never tuned on

The router is compared with baselines and ablations using the checks CI runs. Every number is reproducible with python -m open_skill.benchmark.

08 · get started

Three steps in Claude Code

Or in any of the %%agents%% agents that load Agent Skills (see the list). Upstream frameworks are described, then installed with their own commands:

superpowers BMad Method spec-kit codegraph Graphify Anthropic skills Knowledge-work plugins Context7 ponytail taste-skill addyosmani/agent-skills vercel-labs/agent-skills 
# 1. Install the skills (Claude Code); or: npx skills add VoKhoiNhon/open-skill-standard -g
/plugin marketplace add VoKhoiNhon/open-skill-standard
/plugin install open-skill@open-skill-standard

# 2. Tell it your role(s); this also seeds starter knowledge for them
uvx --from git+https://github.com/VoKhoiNhon/open-skill-standard@v0.7.2 open-skill init --role data-engineer=0.7 --role data-analyst=0.3

# 3. In your agent, inside any project
/open-skill-router add a pipeline that loads orders into the warehouse
