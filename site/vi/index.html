01 · vì sao

Một máy thường có hơn 100 skill trùng chức năng. Open Skill Standard bổ sung lớp thông tin còn thiếu: mỗi skill phục vụ vai trò nào, hoạt động ở phase nào, dùng và sinh ra artefact nào. Từ đó router dựng một chuỗi skill ngắn, đúng thứ tự và có giải thích.

  1. Mô tả trùng nhau

    Agent chọn skill bằng cách so khớp mô tả. Ba quy trình build và vài kiểu review nghe na ná nhau khiến agent nạp sai skill hoặc bỏ sót skill đúng.

  2. Danh sách bị cắt

    Claude Code chỉ dành khoảng 1% context cho danh sách skill và cắt mô tả của skill ít dùng trước, nên càng cài nhiều skill, việc chọn càng kém.

02 · gồm những gì

Bốn skill lõi, một CLI và một registry không bao giờ sao chép nội dung upstream

Skill upstream được mô tả bằng metadata và cài bằng lệnh chính thức của chúng. Router đọc metadata đó; agent của bạn chạy chuỗi skill.

03 · cách hoạt động

Từ registry tới một chuỗi có giải thích

  1. Mô tả và lập indexRegistry và các skill đã cài trên máy đi vào một index SQLite FTS5 cục bộ.
  2. Route theo phase và vai tròXác định phase, cỡ việc và dải phase trước, rồi chấm điểm và chọn theo từng phase, cuối cùng ra chuỗi có thứ tự.
  3. Hỏi vì saoroute --explain và route --why-not <skill> cho thấy mọi quyết định.

Cả hai sơ đồ được sinh từ code và registry sau mỗi thay đổi, nên không thể lệch với thực tế.

05 · session song song

Nhiều agent, một project, một graph chung

Mỗi session khai báo đường dẫn mình phụ trách. Sau khi sửa, open-skill session update cập nhật một graph Graphify dùng chung và cảnh báo, không bao giờ chặn, khi thay đổi chạm tới phạm vi của session khác.

06 · đo lường

Chấm điểm trên các yêu cầu chưa từng dùng để tinh chỉnh

Router được so với các baseline và ablation bằng đúng các kiểm tra CI chạy. Mọi con số đều tái lập được bằng python -m open_skill.benchmark.

07 · skill graph

Mọi skill, theo phase, trong một trang

Artefact, điều kiện, xung đột và vai trò khuyên dùng cho từng skill trong %%skills%% skill. Lọc theo vai trò, phase và nguồn; chạy không cần mạng và dùng được bằng bàn phím.

08 · bắt đầu

Ba bước trong Claude Code

Hoặc trong bất kỳ agent nào trong %%agents%% agent đọc được Agent Skills (xem danh sách). Các framework upstream được mô tả, rồi cài bằng lệnh của chính chúng:

superpowers BMad Method spec-kit codegraph Graphify Anthropic skills Knowledge-work plugins Context7 ponytail taste-skill addyosmani/agent-skills vercel-labs/agent-skills 
# 1. Cài skill (Claude Code); hoặc: npx skills add VoKhoiNhon/open-skill-standard -g
/plugin marketplace add VoKhoiNhon/open-skill-standard
/plugin install open-skill@open-skill-standard

# 2. Khai báo vai trò; lệnh này cũng tạo sẵn tri thức khởi đầu cho vai trò đó
uvx --from git+https://github.com/VoKhoiNhon/open-skill-standard@v0.7.3 open-skill init --role data-engineer=0.7 --role data-analyst=0.3

# 3. Trong agent, ở bất kỳ project nào
/open-skill-router add a pipeline that loads orders into the warehouse
