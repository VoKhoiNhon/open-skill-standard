Chuẩn mở, không phụ thuộc agent, để chọn đúng Agent Skill cho từng việc. Repo kèm bản triển khai tham chiếu, nối superpowers, BMad Method, spec-kit, codegraph, skill của Anthropic và nhiều nguồn khác mà không sao chép nội dung của bộ nào.

Vì sao cần

Agent lập trình ngày nay nạp skill từ rất nhiều dự án độc lập. Một máy thường có hơn 100 skill trùng chức năng: ba quy trình build, vài kiểu review, hai kiểu brainstorm.

Mô tả trùng nhau

Agent chọn skill bằng cách so khớp mô tả, nên mô tả trùng khiến nó nạp sai skill hoặc bỏ sót skill đúng.

Danh sách bị cắt

Claude Code chỉ dành khoảng 1% context cho danh sách skill và cắt mô tả của skill ít dùng trước, nên càng cài nhiều, việc chọn càng kém.

Open Skill Standard bổ sung lớp thông tin còn thiếu: mỗi skill phục vụ vai trò nào, hoạt động ở phase nào, và dùng hay sinh ra artefact nào. Từ đó router dựng được một chuỗi skill ngắn, đúng thứ tự và có giải thích cho mỗi việc.

Gồm những gì

Bốn skill lõi, một CLI, và một registry mô tả skill upstream dưới dạng metadata, không bao giờ sao chép.

open-skill-router

Chọn chuỗi skill cho việc, báo chuỗi trong một dòng, chạy bước đầu và ghi lại những gì đã chạy.

open-skill-standards

Checklist "định nghĩa xong" chung và cho từng vai trò trong 28 vai trò.

open-skill-intel

Đưa mỗi câu hỏi tới nguồn tốt nhất: codegraph, Context7, schema, web, ghi chú của bạn.

open-skill-learn

Ghi nhớ bài học và thói quen ngay trên máy bạn, để các lần route sau dùng.

CLI open-skill

route, search, doctor, session, lint, audit, learn và nhiều lệnh khác.

Registry

Adapter cho các nguồn upstream, role pack và hồ sơ model, được kiểm tra trong CI.

Cách hoạt động

Registry và các skill đã cài đi vào một index trên máy; router thêm thông tin project và ghi chú của bạn, rồi đưa agent một chuỗi có thứ tự, kèm lý do cho từng bước.

28 vai trò IT

Mỗi role pack nêu rủi ro đặc trưng của vai trò, các nguyên tắc, những file trong project gợi ý vai trò đó, cùng skill chính và skill thay thế cho từng phase. Cùng một kiểu yêu cầu nhưng khác vai trò thì ra chuỗi khác.

Nhiều session song song, một graph chung

Nhiều session agent có thể cùng làm trên một project. Mỗi session khai báo đường dẫn mình phụ trách; sau khi sửa, open-skill session update cập nhật một code graph Graphify dùng chung và cảnh báo, không bao giờ chặn, khi thay đổi chạm tới phạm vi của session khác.

Có số đo, không chỉ lời nói

Trên các yêu cầu holdout, router được chấm điểm so với các baseline và ablation bằng đúng các kiểm tra CI chạy, và mọi con số đều tái lập được bằng python -m open_skill.benchmark.

Bắt đầu

Ba bước trong Claude Code; các agent khác đọc được Agent Skills cũng dùng được (xem danh sách).

# 1. Cài skill (Claude Code); hoặc: npx skills add VoKhoiNhon/open-skill-standard -g
/plugin marketplace add VoKhoiNhon/open-skill-standard
/plugin install open-skill@open-skill-standard

# 2. Khai báo vai trò; lệnh này cũng tạo sẵn tri thức khởi đầu cho vai trò đó
uvx --from git+https://github.com/VoKhoiNhon/open-skill-standard@v0.7.2 open-skill init --role data-engineer=0.7 --role data-analyst=0.3

# 3. Trong agent, ở bất kỳ project nào
/open-skill-router add a pipeline that loads orders into the warehouse
